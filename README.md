## ⚡ Quickstart: Run a Worker Node (Incentivized Testnet)

Join the collective AI mesh and earn **$DEAI** testnet rewards based on **Uptime + Compute Workload (TFLOPS)**.

### Option 1: One-Click Windows Launcher
1. Download this repository (`git clone https://github.com/federal216/decentralized-ai.git`).
2. Double-click `start_miner.bat`.
3. Paste your Solana wallet address (or press Enter for default).
4. Watch your node shard DeepSeek-R1 layers and accumulate `$DEAI` rewards!

### Option 2: Command Line (Windows / Linux / macOS)
```bash
git clone https://github.com/federal216/decentralized-ai.git
cd decentralized-ai
python scripts/worker_node.py --wallet <YOUR_SOLANA_WALLET_ADDRESS>
```
